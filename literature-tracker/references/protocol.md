# 运行协议

## 建立学科配置

每个方向至少有一组主题检索词和明确的来源入口。将正式渠道和发现渠道分开：原始出处可包括出版社、学协会期刊、会议论文集、公开评审决定和预印本服务器；索引和机构仓储用于扩大覆盖或补充可读稿本。选择与学科匹配的本地语言来源和权威目录，区分当前目录版本和收录类型。监测名单是可追踪的覆盖承诺，不等于完整的学科排名。

按领域调节证据问题。实证社会科学看样本、测量、识别与稳健性；系统与机器学习看基线、样本外测试、数据泄漏、成本和复现边界；实验科学看对照、重复、测量误差与外部验证；理论工作看假设、论证、反例与适用范围。允许跨类型比较，说明研究问题是否可比。

## 默认判据

| 维度 | 判据 |
|---|---|
| 精读候选 | 有可靠评审或足够强的独立验证，方向高度匹配且有明确深读价值。周报初筛不授予正式精读结论。 |
| 泛读 | 对了解进展、方法或取舍有价值，证据或适用范围有限。 |
| 暂存 | 书目、版本或关键依据待确认，或者价值不足以展示。 |
| A | 已检查支持主要结论的关键正文、方法和结果。未复现时仍说明。 |
| B | 检查了部分正文或详实稿本，关键验证有缺口。 |
| C | 仅核对书目、发表信息和摘要。正式高质量来源且高度相关的候选可保留精读候选，注明“正文待核验”。只有未经确认的发现线索时，内部标“待核”，不把它写成完成C级核验。 |
| 星级（新刊默认显示） | 1–5星表示初步阅读价值，独立于核验深度。若项目已有定义，沿用项目规则；未经可靠评审且缺乏强独立验证的稿件不给五星。 |
| 正式主推 / 简短比较 | 均需有近期依据和核准的书目，可进入正式荐读历史。简短比较是读者版正式条目，篇幅较短。 |
| 前沿观察 | 可展示但需醒目标发表状态及局限，默认不进入正式荐读历史及导入清单。 |
| 内部 | 用于复评、背景和未入选记录，不进入读者版。 |

区分“未发现撤稿或勘误记录”“发现并已核实”“未能核查”。如果原始来源与索引不同，优先以正式版本及权威勘误为准，保存差异。付费墙不自动淘汰论文；它影响能够宣称的检查深度。

### 新刊默认的星级说明

星级用于排列初步阅读优先级，由可信证据、方法和局限、与刊物方向的相关度及阅读收益共同判断。新刊默认显示，可按项目偏好关闭；已有项目按其原定义执行。以下是通用技能的解释尺度，供没有既定逐星口径的新刊使用。

| 星级 | 阅读含义 |
|---|---|
| ★★★★★ | 极少使用。研究贡献和证据有突出价值，且与本刊方向高度相关，优先安排深入阅读。 |
| ★★★★ | 优先阅读。方法、结果或研究问题值得投入时间，仍需结合局限判断。 |
| ★★★ | 值得泛读。适合了解进展或参考局部方法。 |
| ★★ | 优先级较低。通常留作后续复评或补证。 |
| ★ | 阅读收益有限，通常仅保留内部线索。 |

星级是编辑判断，不与阅读标签或 A/B/C 自动换算，也不按固定分数线入选。高层级期刊、影响因子、核心目录或语种不会自动换算成星级；明显的研究缺陷可直接排除精读候选。

### 可选的地区或语种阅读偏好

新刊默认不设偏好。用户可单独选中国国内期刊、中文文献，或自定义一个地区或语种。国内期刊按发表刊物判断，中文文献按论文发表语种判断，均不依据作者国籍或姓名。这个选项和检索语种、监测来源、读者版语言分别配置。

只在总体研究质量和方向相关度相近时使用。逐篇看是否对当地研究情境、数据、方法、写作或目标期刊投稿有具体参考价值，据此轻微调整取舍、阅读顺序或篇幅。不给固定加分或收录配额，不提高星级、精读候选资格或 A/B/C，不弥补证据缺陷，不放宽近期性或评审边界。影响取舍时在比较记录写明理由；无合适论文时仍可零篇。已有项目沿用其明确配置。

## 推荐的归档结构

字段名可沿用项目已有约定。轻量运行可以合并记录，但保留同样的信息。

| 记录 | 最少信息 |
|---|---|
| 配置与运行状态 | 配置版本、期次或运行ID、时区、上次与本次实际截止、阶段状态、读者版和归档结果 |
| 查询与来源 | 方向、渠道、实际检索式或目录URL、执行时间、命中／零命中／失败、证据位置、覆盖限制 |
| 候选与版本 | 稳定标识、题名和作者、方向、正式或预印本标识、各版本状态和日期、来源链接、勘误撤稿状态、证据等级、近期事件及证据 |
| 比较与裁定 | 比较对象、可核证据、主要局限、评级、角色、入选或排除理由；复查发现、证据变化与裁定 |
| 读者版与名单 | 正式荐读、观察各自的名单和读者版位置、输出路径或版本；需要导入时提供仅含核准正式条目的清单 |
| 正式历史与导入核验 | 发布日期、稳定标识、版本与改荐理由；逐条导入状态、目标、实际条目ID及核验结果 |

保留可审计的证据快照、指向合法来源的记录或内容哈希；受许可约束的全文只保留合规访问方式，不随共享包传播。发表时间仅可核至年月时，按年月记录，避免填入推定的具体日。若无合格论文，报告零篇及主要覆盖限制，区分“未发现合格论文”和“关键来源未能查到”。

## 跨学科应用例

- **教育研究**可跟踪实验或准实验、测量与量表、系统综述三个方向。新增期刊论文优先核准发表状态和研究设计，近期会议报告可作进展线索。前后测分数有改善时，须查对照及选择偏差再描述归因。
- **计算语言学**可分任务评测、模型方法、数据与复现。用官方论文集区分主会、Findings、研讨会或演示轨道；同一篇预印本转正式论文只保留一个候选和多个版本。只查到摘要时，把代码公开声明与代码运行核验分开。
